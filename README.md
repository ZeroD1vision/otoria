# Otoria

> Голосовой ассистент совмещающий лучшее из мира помощников: колонка +  + управление ПК.

Программно-аппаратный комплекс контекстно-зависимого голосового ассистирования рабочего пространства пользователя с элементами графического и тактильного взаимодействия.

Проект разделён на три независимых бинарника, живущих в одном монорепозитории, но у каждого свой владелец.

| Модуль | Суть | Владелец | Стек | Место запуска |
|---|---|---|---|---|
| Аппаратная часть и низкоуровневое управление звуком | **soma** ("тело") | @sanlexandro | ... | Orange Pi |
| Оркестратор, STT/TTS, LLM, DevOps, Инфраструктура | **anima** ("разум") | @ZeroD1vision | Go | Orange Pi / Сервер |
| Десктоп-агент и UI | **manus** ("рука") | @TrySquadDF | ... | Пользовалеьский ПК |

Полный список формальных договорённостей - в [`GOVERNANCE.md`](./GOVERNANCE.md).
Как контрибьютить (коммиты, ветки, PR, оформление и т.п.) - в [`CONTRIBUTING.md`](./CONTRIBUTING.md).
Архитектура и протоколы - в [`docs/ARCHITECTURE.md`](./docs/ARCHITECTURE.md).

## Структура репозитория

```
otoria/
├── soma/                   #   @sanlexandro - прошивки, аудио-демон, hotword
│   ├── firmware/           #   прошивки МК (платы часов/кнопок)
│   ├── audio-daemon/       #   демон захвата звука на Orange Pi
│   ...
│   └── cad/                #   3D-модели корпуса
│
├── anima/                  # @ZeroD1vision - оркестратор, бэкенд, инфра
│   ├── cmd/core/           #   точка входа
│   ├── internal/
│   │   ├── stt/            #   распознавание речи
│   │   ├── tts/            #   синтез речи + нормализация текста
│   │   ├── llm/            #   абстракция над LLM-провайдерами
│   │   ├── session/        #   управление сессиями и все такое
│   │   ...
│   │   └── filter/         #   вторичный слой фильтрации стоп-слов
│   └── deploy/             #   Dockerfile, systemd unit, и все что связано с деплойментом
│
├── manus/                  # @TrySquadDF - десктоп-агент и UI
│   ├── cmd/agent/          #   точка входа
│   ├── internal/           #   внутренние файлы
│   ...
│   └── ui/                 #   интерфейсные файлы
│
├── proto/                  # Общие контракты между всеми тремя модулями
│   ├── audio.proto         #   формат аудио-пакетов soma → anima
│   ...
│   └── control.proto       #   формат команд anima → manus (gRPC/WebSocket)
│
├── infra/                  # Docker Compose, CI/CD, конфиги сервера (общая зона)
│   ├── docker/
│   └── ci/
│
├── docs/
│   ├── ARCHITECTURE.md
│   ├── adr/                # Architecture Decision Records - все обсуждаемые вопросы
│   ...
│   └── diagrams/
│
├── scripts/                 # скрипты разработки
├── .github/                 # шаблоны issue/PR, workflows CI, CD
├── GOVERNANCE.md
├── CONTRIBUTING.md
├── CODEOWNERS
├── VERSIONING.md
└── README.md
```
